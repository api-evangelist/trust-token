# Trust Token (Archblock)

> TrustToken, rebranded as Archblock in November 2022, builds infrastructure for moving institutional funds and real-world assets onto blockchain rails. It created the TrueUSD (TUSD) stablecoin and TrueCurrencies, launched the TrueFi on-chain lending protocol (TRU token), and now operates a fund-tokenization marketplace for institutions at app.archblock.com. Backed by a16z, Founders Fund, BlockTower, and Morgan Creek. No public REST API or developer portal is currently published; the developer surface is the trusttoken GitHub organization (smart contracts, audits, bug bounties) and npm packages under the @trusttoken scope.
